# DevTasks App (Frontend)

Aplicação cliente Flutter do DevTasks (gestão de tarefas para desenvolvedores).

## Módulo do Workspace

Este pacote faz parte do workspace raiz (`devtasks`).
- Nome do pacote: `devtasks_app`
- Camadas: VSA (`lib/modules/<modulo>/{domain,infrastructure,presentation}`) + kernel `global/`.
